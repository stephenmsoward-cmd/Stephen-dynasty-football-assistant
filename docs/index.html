What this is

For each team in a Sleeper dynasty league, this site computes the optimal starting lineup from all rostered players (excluding taxi and IR) using the league's actual slot configuration. Values come from FantasyCalc's dynasty trade values and reflect multi-year expected production with age baked in.

It's a way to see how teams stack up if everyone fielded their best possible lineup each week — the "best ball" version of the standings.

Add your league
