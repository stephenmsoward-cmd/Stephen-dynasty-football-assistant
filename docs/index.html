How it works

For each team in a Sleeper dynasty league, the site solves for the optimal starting lineup from all rostered players (excluding taxi and IR) under the league's actual slot configuration. Player values come from FantasyCalc — dynasty values (multi-year, age-weighted) and win-now redraft values — so every ranking, trade, and target is grounded on the same live numbers rather than a model's memory.

Everything rebuilds nightly from the Sleeper and FantasyCalc APIs, so rosters, injuries, and values stay current through the season.
