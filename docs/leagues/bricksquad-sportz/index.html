Methodology

For each roster, we exclude taxi-squad and IR players, then solve for the lineup that maximizes total value under the league's slot configuration (QB / RB / RB / WR / WR / TE / FLEX / FLEX / FLEX / K / DEF / BN / BN / BN / BN / BN / BN / BN / BN / BN / BN / BN / BN / BN / BN / BN / BN). FLEX slots take the highest-value RB / WR / TE remaining after position-locked slots are filled.

Two modes:

  • Dynasty — FantasyCalc dynasty trade values: multi-year expected production with age weighted in. Best for long-term roster strength.
  • Win Now — FantasyCalc redraft values: this season only. Aging veterans rank higher here than in dynasty mode.

Data freshness: FantasyCalc redraft values reflect the live community trade market and refresh nightly. Expect them to sharpen meaningfully once NFL camps open in late July and beat reporting / ADP firm up — preseason rookie values are FC's noisiest signal right now.

The rank-delta column shows where a team's rank in the other mode lands. ▲ means they rank higher in the other mode (e.g. a rebuild team ranks higher in Dynasty than Win Now); ▼ means lower. Big deltas signal a clear strategic timeline.

Position rank tags (e.g. RB#5) indicate where the player ranks against every other rostered player at that position in the league, under the active mode.

Kickers and team defenses currently show value 0 — FantasyCalc doesn't track them, and they have negligible impact on dynasty valuation.
