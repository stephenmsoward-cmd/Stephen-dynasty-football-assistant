Methodology

For every candidate (1-for-1, 2-for-1, 1-for-2, 2-for-2 — including draft picks), we recompute the optimal best-ball lineup for both teams under the active value mode, and compute the change in each team's total dynasty asset value. A candidate is shown when each team improves on at least one of those two dimensions, with FantasyCalc value parity within 20%.

Dynasty mode uses FantasyCalc dynasty values (multi-year, age-weighted). Win-Now mode uses redraft values (this-season market value).
